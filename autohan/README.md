# AutoHan

Type Korean and English on your Mac without pressing 한/영.

AutoHan is a macOS input method for people who type in both languages. You type on a QWERTY
keyboard, using the standard 2-Set (두벌식) Korean layout, and it decides word by word.

```
dkssudgktpdy hello world    →  안녕하세요 hello world
dhsmf meetingdms auctldi?   →  오늘 meeting은 몇시야?
3tl 10qns                   →  3시 10분
```

It won't always guess right. Some Korean words use the same keys as English words: 내 and `so`
are typed the same way, for example, so AutoHan goes with the language you're already in. When
it's wrong, tap **Right ⌘** to switch the word you're typing, or the one you just finished if
the app allows it.

## Status

Early version (0.1), not available to download yet.

So far it has been tested on macOS 27 on Apple silicon, and confirmed working in Notes, VS Code
and text boxes in Chrome. It's built for macOS 13 or later, but older versions of macOS, Intel
Macs and most other apps haven't been tested yet.
